# Note Narrator docs

Documentation for [Note Narrator](https://github.com/pablokvitca/note-narrator), an Obsidian plugin that reads notes aloud with ElevenLabs text to speech.

This repository is an **Obsidian vault**. Open the folder as a vault in Obsidian to edit it. It is published with Obsidian Publish.

- Start at `index.md`.
- Conventions, publishing steps and the screenshot checklist are in `Meta/` (not published).
- Screenshots go in `Screenshots/`.

| Folder | Contents |
| --- | --- |
| `Getting Started/` | Installation, quick start, ElevenLabs setup |
| `Using Note Narrator/` | The panel, reading, playback, saving, highlighting, background jobs, commands |
| `Settings/` | One page per settings group |
| `Reference/` | Frontmatter properties, limitations, privacy, troubleshooting |
| `Roadmap/` | Shipped, in progress and planned work |
| `Meta/` | Authoring notes and screenshot checklist |
